# Images

Product and site photography for the UAC Services website.

## Squeegee range

Real product photos of the UAC squeegee, one per colour in the range. Each
shows the head (with blue bristle scrubber + black rubber blade) beside its
matching handle, shot on a plain white background.

| File | Colour |
|------|--------|
| `squeegee-red.jpg` | Red |
| `squeegee-blue.jpg` | Blue |
| `squeegee-black.jpg` | Black |
| `squeegee-dark-grey.jpg` | Dark grey |
| `squeegee-light-grey.jpg` | Light grey |

## Conventions

- Filenames all-lowercase, words separated by hyphens, no spaces.
- Keep photos web-optimised: ~1200–1600px on the long edge, compressed to a
  few hundred KB. Straight-off-the-phone files (multiple MB) should be
  resized before committing so pages stay fast.
- Prefer `.jpg` for photographs, `.svg` for logos/icons.
